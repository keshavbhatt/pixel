# pixel

**Archived.** This was the image tool behind PixelFx 1, a small command line program over
[gift](https://github.com/disintegration/gift). PixelFx 2 replaces it with libpixelfx, an
in-process C++ library: https://github.com/keshavbhatt/PixelFx/tree/main/libs/pixelfx-core

PixelFx 1 itself is on the `legacy-v1` branch of https://github.com/keshavbhatt/PixelFx
